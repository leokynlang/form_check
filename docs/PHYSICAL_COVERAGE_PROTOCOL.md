## 4. 统一外域与源约束

外域政策固定为 `official-positive-branch-central90-v1`，适用于全部目录：

1. 在原始采样分布允许的符号分支内，条件化为严格正输入；保留原变量、数值尺度、物理常数和表达式。
2. DefaultSampling 在原正值 log 坐标支持上取 5%–95% 区间；SimpleSampling 在原允许正支持的线性坐标上取相同分位。不能为某个式挑有利正弦叶瓣或另找量级。
3. IntegerSampling 先保留上游 `randint(low,high)` 的右端不包含语义，再取允许符号分支的正整数并集，在其离散 CDF 上取 5% 与 95% 整数分位。派生的闭区间端点包含在内；不足两个值的设计记 unresolved。
4. **整个派生外盒**必须满足源分母非零、根号／对数域、明确源约束及物理假设。源中具名速度须保持亚光速。不能只检查若干角点或随机点，就宣称整盒有效。
5. 不允许以绝对值、输出平移、符号翻转、变量换单位或新物理前因子改变源法则。源未给明确单位时记 `evidence_missing`，保留变量描述，不能仅凭名称补写 SI 单位。

源约束的每一项证明／未解理由保留在逐式表中。源描述出现越出变量数的索引时，列 `source_contract_review_pending` 和对应证明义务，不静默解释。某些式在 P0-2 的逐式有效域内可用，在本轮统一外盒上却不能严格正或有限；本轮仍保留 unresolved，不能回用个别旧域来绕过统一规则。

当前数学证据使用 80 位小数精度的向外区间计算，并保留完整盒下界／上界；没有随机点或网格点筛选。两项需要消除区间依赖的几何／比值恒等式经过符号等式检查后使用，仍保留原式和常数。这些是供独立审查的计算辅助证据，不能把区间未证当成数学反例，也不能把自动分组当成一般代数独立性的证明。

## 5. 结构组的两层边界

自动连接检查涵盖变量重命名、全局比例常数、可分离单项式前因子、整个目标的固定非零幂或倒数，以及来源式变体。固定目标幂／倒数在 log 目标上只改变比例或符号，不能被包装成新机制。

全 120 式还统一计算细 Laurent-sum 标签：去掉单项式前因子和一个整体输出幂后，是否剩下正系数 Laurent 单项式之和。这个标签不包括求和内部嵌套的非线性项，也不包括展开后的负交叉项，算法对全部条目执行，不能只给某一候选开例外。

主要暴露族进一步保守合并正项和、范数和嵌套根式组合。Bonus16 的根外电势项与根内动量差平方构成较细的嵌套相对论能量组合；它不符合单一 Laurent-sum 整体幂的细语法，但也不能据此断言与已见正和／范数是独立机制。主要分析保守归 development，细结构争议完整保留。

主要连通分量可能过度合并，从而减少独立组数；这种保守性应公开。未来若要改变机制分辨率，必须在新数据前对全 120 式统一专家审查规则，而不是只裁定唯一新候选，更不能用未来实验表现决定分组。

H0 始终共用幂律假设族。新增 H0 来源／输入分布只能检验设计迁移，不能称为未见函数假设族验证。

## 6. 所有纳入组共同的因子设计与终点

在执行注册完整后，所有科学纳入组及其来源变体共同交叉以下网格：

| 因子 | 注册值 |
|---|---|
| 训练宽度 | 外盒原坐标跨度的 25%、50%、75%，统一居中 |
| log 噪声标准差 | 0.005、0.01、0.03、0.05 |
| n | 200、1000 |
| 测试重复 | 每格 100 次 |

n 的选择只依据最大 8 维全二次模型有 45 列、五折训练需要基本行列可行性；不是看功效结果后决定。整数训练窗口仍保留真实整数支持，各宽度都须满足非退化训练与可表示外推方向；不能将整数特征改成连续数来补齐网格。

R²≥0.99 只用于下游放行规则，不决定某式是否入组。全部拟合筛选失败、诊断无法评估、区域结果不可用的记录均保留在工作流分母。不能只跑容易达到高 R² 的宽度或噪声格。

主终点固定为采样前外推区域上的加权平均相对误差，危险阈值为 10%；次级报告加权 p95、最大误差、连续误差分布，以及 2%、5%、20% 阈值。区域坐标、方向权重和 log 真值在采样前冻结，不删除数值较难或误差较大的点。目标为无噪声 log-location／条件中位数，不能误写成 lognormal 算术均值。

A–G、五种既有策略、1%／5%／10% 联合预算和 10 轮独立参考／校准的规则写入 JSON。配对不确定性以整 H1 结构组及 H0 设计组为重采样单位。来源条目数、独立组数和有危险分母的组数分别报告。
