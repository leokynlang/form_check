## 结果边界

在共同5%校准预算下，n=1000／噪声0.03时，F的危险放行率为9.36%［3.54%,13.76%］，AEF为15.65%，配对 AEF−F 为6.29［2.47,9.00］个百分点。不同政策的实际H0测试成本不同；低噪声下若干差异区间包含零，不能据此声称F全面支配。区间条件于固定校准设计池、结构组和已实现测试记录。

所有12格物理来源子池的条件主风险分母均为零，必须报无定义。整个工作流在3,600次已观察主危险物理拟合上放行0次，均由R²筛选拦住；这不能归因于后续门控，也不能推广成物理总体的零风险。扩大物理来源覆盖的新协议另行登记，尚未运行新物理数据。
