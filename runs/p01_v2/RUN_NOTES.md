## 尾部问题的验证

v1 的经验 CDF 会把超出参考最大值的不同统计量映射成相同上限，严格预算
可能使面板完全无法报警。v2 保留参考范围之外的排序，测试覆盖了这一病理例。

在全新数据上，AEF 面板于 n=50、1% 目标下的20/20轮均有非零 H1 报警。
这确认人工 CDF 上限造成的全静默已解除。A 的999次置换分辨率、浮点 p 值
下溢和原始统计量自身的平局仍可能存在，已在 `score_diagnostics.json` 单独计数。

## 重复校准不确定性的解释

本轮保存四种互补描述：

1. 轮间 SD、最小/最大值、经验2.5%–97.5%范围：表示更换参考/校准样本的敏感性，该范围不是置信区间。
2. 固定20轮已拟合策略的配对任务 bootstrap。
3. 固定测试任务、重采样20个校准轮的均值区间。
4. 同时重采样轮和 H0/H1 分层测试任务的交叉区间；任务权重跨轮、跨策略共享。

例如 n=50、F：危险放行率20轮均为7.98%，轮重采样区间也为7.98%–7.98%；
加入任务构成差异后，交叉区间扩大为0–48.15%。因此重复校准稳定并不代表跨方程证据充分。

危险分母仅来自 n=50 的6个任务、n=200 的4个任务。5%目标下 AEF 的危险
放行仍全部来自 bonus.15。n=200 风险 bootstrap 有19/2000次零分母，区间使用
1981次有定义抽样，并明确记录次数，未将零分母当作零风险。

配对结果也需保守解释：n=50 的 D-F 危险放行差为+26.75个百分点，交叉区间
为−1.35至+45.00个百分点；n=200 的 A-D 与 D 差为−1.15个百分点，区间为
−6.88至0个百分点。点估计上的优势不足以建立普遍排序。

所有区间条件于既有 H0 校准方程身份、已实现校准轮和共享测试库；没有重新
抽取校准方程群或对测试记录进行内层重抽样。正式的新结构泛化与固定区域结论仍需 P0-2。
